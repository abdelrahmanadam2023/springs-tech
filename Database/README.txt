Database setup (Supabase) - see the steps in the chat.

1) database.sql  -> run once in Supabase > SQL Editor
2) Data/config.js -> paste your Project URL and anon/publishable key
3) Push to GitHub

To add a project: Supabase > Table Editor > projects > Insert row.
To hide one: set is_published = false.
Never put the service_role / secret key in any file of this website.
